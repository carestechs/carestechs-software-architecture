# Lowercase Database Naming via OnModelCreating

**Category:** database
**Status:** Active
**Requires:** `adrs/deployment/flyway-migrations.md`
**Conflicts with:** `adrs/database/snake-case-naming.md`

## Decision

All database table and column names are lowercase (no underscores, no PascalCase). EF Core maps C# PascalCase property names to lowercase via a loop in `OnModelCreating` that calls `ToLower()` on table names, column names, key names, foreign key constraint names, and index names. This matches PostgreSQL's behavior of folding unquoted identifiers to lowercase, ensuring consistency with hand-written Flyway migrations.

## Rationale

- PostgreSQL folds unquoted identifiers to lowercase. Writing migrations with lowercase names and configuring EF Core to match eliminates quoting issues and ensures queries work identically whether generated by EF Core or written by hand.
- Alternatives considered: `UseSnakeCaseNamingConvention()` package (rejected — adds a dependency and produces `snake_case` names like `created_at`, which is inconsistent when Flyway migrations use `createdat`), manual `[Column]` attributes (rejected — tedious and error-prone at scale), PascalCase with quoting (rejected — requires double-quoting in all raw SQL and Flyway migrations).
- When to choose: this ADR fits Flyway/hand-written-SQL stacks (its `Requires` reflects that); choose `snake-case-naming` instead when the ORM owns the schema via EF Core or Alembic migrations.
- The `OnModelCreating` loop is a single reusable pattern copied into each module's DbContext. It processes all entities, properties, keys, foreign keys, and indexes automatically — no per-entity configuration needed.

## Constraints (non-negotiable for AI)

- Every DbContext MUST include the lowercase naming loop in `OnModelCreating` that applies `ToLower()` to table names, column names, key names, FK constraint names, and index names.
- Flyway migration scripts MUST use lowercase names for all tables and columns (e.g., `createdat`, `clientid`, `isactive`).
- NEVER use `UseSnakeCaseNamingConvention()` or any external naming convention package.
- NEVER use `[Column]`, `[Table]`, or `[Key]` attributes for name mapping — the `OnModelCreating` loop handles all translation.
- Raw SQL queries (if any) MUST use lowercase, unquoted identifiers.
- C# entity properties MUST remain PascalCase (e.g., `CreatedAt`, `ClientId`, `IsActive`).
